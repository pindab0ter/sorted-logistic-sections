This is a fork of Tulius' [mod](https://mods.factorio.com/mod/logistics_requests_sorted) updated for Factorio 2.1 with
support for the new logistic sections.

Download the mod from the [Factorio Mods Portal](https://mods.factorio.com/mod/sorted-logistic-sections)

## Features

- Keep your logistic sections sorted
- Toggle sorting with a quickbar button or a hotkey
- Sorting is also applied when pasting entity settings or blueprint settings
- Logistic sections in ghosts are sorted when closing their GUI
- Optionally start each subgroup on a new row (per-player mod setting)
- Multiplayer compatible

## Usage

While sorting is enabled, an entity’s logistic sections are sorted when you open it and whenever you
change them. Entities you never open are left alone.

Sorting a section that belongs to a named group re-orders that group for every entity sharing it.
